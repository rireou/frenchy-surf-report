Archive health
Every archive preserves raw provider inputs, tide tables, exact calculation sources, production output, frozen Model D and provenance. An incomplete write is never treated as an advance forecast. No archive is backfilled from a beach check.
Download private memory and evaluation state · Keep exports private.
Collect successes as well as failures
Record ordinary accurate forecasts too. A convenient time-based check schedule helps prevent an error-only dataset.
  • Westerly swell above 245°
  • 225–235° swell
  • N/NE/E winds
  • Long-period swell (at least 14 s)
  • Larger offshore events (at least 2.8 m)
  • A range of tide stages and ordinary conditions
Keep typical wave size and occasional set size separate. Optional confidence and unusual local factors help interpret uncertainty.
